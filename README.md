# Flaskメモアプリ

このリポジトリは、Flask を用いて作成したシンプルな Web アプリケーションです。メモ管理機能に加え、天気情報の取得や料理レシピ検索の機能を備えています。認証機能付きで、学習用や小規模なプロジェクトの雛形として利用できます。

## 主な機能

- **ログイン機能**：環境変数に設定したユーザー名とパスワードで認証します。
- **メモアプリ**：メモの登録・削除を行う簡易的なメモ管理機能です。データは PostgreSQL に保存されます。
- **天気情報取得**：都道府県や地域を選択し、日本気象庁が提供する API から天気情報を取得します。
- **レシピ検索**：楽天レシピ API を利用して、キーワードに関連する人気レシピを検索・表示します。

## セットアップ

1. Python 3 系が動作する環境を用意してください。
2. 依存パッケージをインストールします。

```bash
pip install -r requirements.txt
```

3. PostgreSQL を用意し、メモ用のデータベースを作成します（接続文字列を `MEMO_DATABASE_PATH` に設定します）。
4. 天気情報用の SQLite データベースを生成する場合は `create_weather_db.py` を実行します。

```bash
python create_weather_db.py
```

## 環境変数

アプリを実行する前に以下の環境変数を設定してください。

| 変数名 | 用途 |
|--------|------|
| `FLASK_SECRET_KEY` | Flask のセッションで使用する秘密鍵 |
| `APP_USERNAME` | ログインに用いるユーザー名 |
| `APP_PASSWORD` | ログインに用いるパスワード |
| `MEMO_DATABASE_PATH` | メモ機能で使用する PostgreSQL の接続文字列 |
| `DATABASE_PATH` | 天気情報で使用する SQLite ファイルへのパス（例: `weather_regions.db`） |
| `RECIPE_CATEGORYLIST_API_KEY` | 楽天レシピカテゴリ一覧 API の URL（アプリケーション ID を含む） |
| `RECIPE_CATEGORYRANKING_API_KEY` | 楽天レシピランキング API の URL（アプリケーション ID を含む） |

## 使い方

1. 上記の環境変数を設定後、以下のコマンドでアプリを起動します。

```bash
python app.py
```

2. ブラウザで `http://localhost:5000` を開き、ログイン画面にアクセスします。
3. ログイン後、画面上部のナビゲーションからメモ、天気情報、レシピ検索の各ページに移動できます。

## ファイル構成

- `app.py` - ルーティングと認証処理を担うメインファイル
- `memo.py` - メモの CRUD 処理を行うモジュール
- `weather.py` - 天気情報の取得処理を行うモジュール
- `recipe.py` - 楽天レシピ API を利用した検索処理
- `templates/` - 各ページの HTML テンプレート
- `static/` - CSS などの静的ファイル
- `create_weather_db.py` - 天気情報用の SQLite データベースを作成するスクリプト

## デプロイ

Vercel でのデプロイを想定した `vercel.json` を含んでいます。Vercel 環境でも上記の環境変数を設定してください。
